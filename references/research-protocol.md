# 搜索与证据协议

实际采集或处理边界数据时读取。所有数值门槛都是本次研究参数，不是小红书官方定义。

## 能力与入口

1. 检查当前可调用工具。连接器必须实际提供搜索/详情能力；只有工具名称相似不算可用。
2. 浏览器路径：遵守当前浏览器工具文档，读取现有页面状态，定位小红书搜索与筛选控件，执行后再确认状态。不要猜 CSS 选择器、内部 API 或响应字段，不从浏览器之外读取 cookies。
3. 已有材料路径：保留用户提供的数据与来源；不要把手工摘录说成当场联网核实。
4. 无可用小红书访问能力时：可用普通网页搜索找线索，明确覆盖不足；交付关键词和已知材料分析，说明需要的登录/链接/导出数据。不要伪造满额结果。
5. 不自动安装依赖、购买采集服务或上传用户资料来补能力。付费服务只有在用户已指定并具备相应权限时才使用。

## 关键词与两轮检索

从请求构造少量不同意图的关键词，优先搜精确词，再扩展场景词。例如主题是 AI 教程，可先搜“AI 教程”“AI 办公 实操”“AI 视频 制作流程”。这些只是示例，不是永久默认主题。

- 第一轮：以最新结果找近期样本；逐条检查日期。排序成功不代表所有结果都落在时间窗内。
- 第二轮：使用页面实际提供的高互动排序或相关组合词补漏；老爆款仍需按日期排除。
- 用户要同主题不同形式的内容时分组；不要跨图文、短视频、长视频强行比较同一种留存指标。
- 每轮记下查询词、排序、加载批次、扫描和新增数量。两次连续加载无新增就结束该入口。
- 默认 100 个去重候选是成本上限，不是必须读满；达到目标就停止。用户要求 100 条合格结果时，相应提高候选预算，分批保存并报告当前进度。
- 不足时先报告原因，可提出延长时间窗或调整门槛；只有用户已允许灵活条件时才另列放宽后的样本，并标明新口径。

## 先粗筛再深读

搜索卡片记录：标题、作者、笔记链接、可见互动、显示日期和内容形式。

详情补充：实际发布时间、点赞/收藏/评论、正文结构；有低粉条件再读取作者主页粉丝数。只有高互动条件的任务不必为了凑字段逐个打开作者主页。

阅读优先级是“可能符合硬条件且与目标相关”，不是先把全部候选详情读完。最终展示的缺失项保持缺失。

## URL 与去重

- 记录 `source_url`：实际观察到的原始链接，保留完整 query，尤其可能影响访问的 `xsec_token` 等参数。
- 单独记录 `note_id` 作为去重键。从实际 URL 或工具响应提取；不生成不存在的 ID。
- 同一 ID 多次出现只算一篇，合并命中的关键词。若有多个访问链接，优先保留实际打开成功的一条，并可保存其他原始链接。
- 短分享链接可以正常打开以读取最终地址；无法解析时保存原链接，不把不同未知链接强行判为同一篇。
- 相同标题、相同作者不必然是同一篇；没有 ID 时标记疑似重复。
- 清理参数后的路径可用于内部比较，但不能替换已经取得的原始交付链接。不得编造访问 token。

## 数值与时间边界

原始显示值和解析值分开：

| 显示 | 处理 |
|---|---|
| `1,280` | 解析为 1280，保留原值 |
| `1.2万`、`1.2w`、`1.2W` | 约 12000，精度标记 approximate |
| `2.3千`、`2.3k` | 约 2300，精度标记 approximate |
| `999+`、`1万+` | 下界/含糊显示，不能当精确值排序；跨门槛或语义未核实时待核实 |
| `赞`、`--`、隐藏、未读 | null，原因写 unknown，不计为 0 |

当近似值贴近硬阈值（例如“1.0万”对粉丝≤10000）时，无法证明在界内，列待核实。`1.2万赞` 对最低 1000 赞明显满足数值条件，但仍保留近似标记；严格要求精确值时继续核实。合计互动仅在所有组成项已知时计算，缺任一项就不算总值。

- “最近 30 天”默认按用户时区含今天的 30 个自然日；2026-09-30 对应 2026-09-01 至 2026-09-30。用户指定滚动小时窗口时照其要求。
- `3天前` 等显示值以采集时刻解释，保留原样和日期精度。只有月日、年份不明或时间窗边缘有歧义时继续核实。
- 主页粉丝数是采集时的粉丝量；一篇爆款本身可能已带来涨粉，不能倒推出发布时的账号体量。
- 不用点赞/当前粉丝计算“互动率”，不把一天内的单点数字称为增速。研究增速需要至少两次有时间戳且口径一致的观测。

## 覆盖、阻塞与可信度

登录/验证出现时停止该入口的自动采集，保留已经合法读到的内容。报告“已扫描多少、已保存多少、哪些字段缺失、继续需要什么”。没有持续重复请求或绕过验证的后续步骤。

最终状态分开描述：

- **筛选资格**：符合 / 待核实 / 不符合。
- **内容深度**：卡片 / 详情 / 全文或视频 / 评论。
- **来源方式**：现场页面 / 连接器 / 用户材料 / 搜索摘要。

“符合筛选门槛”不代表完整内容已读，也不代表可复刻或已证明流量成因。所有排序都是已采集样本范围内的排序；不声称全站 Top N 或完整抓取。
